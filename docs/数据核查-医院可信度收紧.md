# 应急医院数据可信度收紧（v1.19.180）

> 本文档记录一次**数据质量决策**，不是功能新增。判据与结论都可复跑：`node tools/_hospital-verify-split.mjs --report`。

## 一、问题

v1.19.168 为回应「医院还是太少了」，用「城市名 + 固定后缀」批量生成医院条目，把覆盖从 321 城推到 451 城。判据：

```
名称 === 城市名 + 人民医院 / 中医院 / 妇幼保健院 / 中心医院 / 第一人民医院 …
坐标   = 城中心 ±0.02° 平移（并非实测位置）
```

抽查发现的典型错误：

| 城市 | 生成条目 | 实际 |
|---|---|---|
| 三沙 | 三沙中医院、三沙妇幼保健院 | 三沙市无常设中医院/妇幼保健院 |
| 茫崖 | 茫崖中医院、茫崖妇幼保健院 | 戈壁县级市，无此机构 |
| 那曲 | 那曲妇幼保健院 | 海拔 4500m，无此机构 |
| 北京 | 北京人民医院 | 真名为「北京大学人民医院」 |

应急场景下给出一个并不存在的机构名与 1.3km 距离，比「本城暂未收录」更危险。因此收紧。

## 二、处置

| 项 | 收紧前 | 收紧后 |
|---|---|---|
| 具名医院 | 1728 家 | **156 家** |
| 有具名医院的城市 | 451 城 | **125 城** |
| 仅有城中心坐标的城市 | 0 | **326 城** |
| 应急数据体积 | 170 KB | **33 KB** |

- `HOSPITALS` 只保留具名真实机构（经 geocode 地址核验：地址含「医院」且距城中心 ≤25km）。
- 被清空的城市进入 `APPROX`：只存城中心坐标，UI 改为「在地图中搜索附近医院」按钮，不再列机构名。
- 回归新增红线：**HOSPITALS 中不得出现模板名**，防回潮（`tools/test/_test-emergency.mjs`）。
