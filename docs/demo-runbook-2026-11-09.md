## 二、环境准备（演示前必做，建议提前 10 分钟）

### 方案 A（推荐，最稳）：网页版
```bash
cd outputs/miniprogram-travel
bash tools/demo-serve.sh          # 默认 8899 端口
# 浏览器打开： http://127.0.0.1:8899/index.html
```
- 完全离线（本地 python 服务 + 随包数据），不依赖外网与账号。
- **若页面空白**：`Cmd+Shift+R` 强制刷新（绕过 PWA Service Worker 缓存）。
- 限制：浏览器无原生地图组件、不加载在线底图；**地图页已改为「真实坐标示意图」（编号标点 + 当天连线 + 美食/住宿配色）+ 高德跳转**，完全离线可讲。真实底图仍需开发者工具。

### 方案 B（演示「真实地图」必用）：微信开发者工具
1. 微信开发者工具 → 导入项目 `outputs/miniprogram-travel`（AppID `wxa365d49bc3366f95`）。
2. 编译 → 模拟器运行；需要真机效果用「真机预览 / 真机调试」。
3. 地图页可展示原生底图、编号标点、当天连线、美食/住宿图层。

### 方案 C（备份）
- 网页版 + 手机热点（除地图底图外全部离线可用）。
- 小程序已有「备份导出 / 导入」（更多页），可预置一份存档演示。
- 演示前跑一次 `bash ./allcheck.sh > /tmp/allcheck-demo.log 2>&1` 留存「61/61 全绿」日志截图。

## 三、5–8 分钟演示脚本（按讲故事顺序，覆盖完整度 + 创意落地）

1. **首页（出发）**：出发地→目的地 / 全省精华游 / 多站串联；搜索选城；预算档、人数、天数、节奏。
2. **生成**：选「成都 / 5 天 / 舒适 / 平衡」→ 一键生成（展示速度与稳定性）。
3. **行程页**：逐日时间线（上午/下午/晚上）、动线、门票预约清单、住宿建议、可换一批景点。
4. **地图页**：网页版展示「真实坐标示意图」（编号标点 + 当天连线 + 美食住宿配色，离线可讲）；要真实底图用方案 B 开发者工具。
5. **美食页**：地道名店、招牌菜单、口碑点评。
6. **记账**：快速记账（如「午餐88元」自动解析）、AA 分账、预算进度条。
7. **准备页**：票务勾选、行李清单、日历 `.ics` 导出。
8. **更多 + 长图**：旅行画像/成就、字号/主题、**攻略长图 / 分享图导出**（创意落地 + 工程完成度）。
9. **收尾**：亮出「61/61 回归门禁全绿 + 代码质量报告」（见 §五）。

## 四、答辩要点（对照评分，提前背熟）

- **选题与创新**：面向大一新生的「零门槛旅行攻略生成」——纯前端、完全离线、覆盖全国 751 城；AI 式结构化生成 + 可解释评分。
- **技术路线**：小程序 + 同源编译网页版；数据分包 + pako 压缩解压；纯前端无后端（合规且零成本）。
- **vibe coding 质量怎么讲**（关键加分项）：
  1. **AI 生成 + 人审 + 护栏**：所有改动过 61 步回归门禁（语法/依赖/凭据/数据健康/40+ 单测/WXML/导航/体积/发布安全/网页同源）。
  2. **缺陷防线**：100+ 条代码审计（数据真实性/安全/性能/可维护/架构）；行程生成 **fuzz 引擎**（340 次构建捕获异常/NaN/越界/空天）。
  3. **防回潮**：每条踩过的坑都固化为断言（如「catch 不得伪装空态」「发布代码不得残留调试语句」）。
  4. 证据：`docs/code-audit-2026-11-09.md`、`docs/code-quality-report-2026-11-09.md`。
- **团队分工**：按通知要求讲清 组长 / 项目设计 / 代码实现 / 计划书 / PPT 的责任人。

## 五、现场风险与应对

| 风险 | 应对 |
|---|---|
| 网页版页面空白 | `Cmd+Shift+R` 强刷（PWA 缓存）；重跑 `bash tools/demo-serve.sh` |
| 地图要真实底图 | 切微信开发者工具（方案 B）；网页版有「真实坐标示意图」（散点+连线），如实说明不加载在线底图 |
| 天气/联网功能失败 | 已做降级，不阻塞主流程；如实说明「需联网，失败不阻断」 |
| 数据加载慢 | 启动层遮罩 + 失败重试按钮；等待即可 |
| 现场断网 | 网页版本地服务 + 随包离线数据可完整演示（地图除外）|
| 被问「有没有后端」 | 如实：纯前端离线，规避个人主体 web-view/支付合规限制；升级主体后可扩展 |
