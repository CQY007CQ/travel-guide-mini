> 用途：实验室纳新分享会 / 项目评审 的功能总览附件。

## 一、攻略生成引擎（核心）
入口：首页「出发」+ 核心模块 `utils/travel.js` / `utils/planner.js`

- **基础参数**：选城市、天数、节奏（轻松 / 标准 / 紧凑）、预算档（经济 / 舒适 / 豪华 + 自定义金额）、出行方式、人数（1–10）。
- **想玩清单（指定必玩）**：手动勾选「这趟一定要去」的景点，生成时优先排入。
- **多站串联（≤4 站）**：一次规划多个城市，自动计算路线概览与跨城衔接。
- **全省精华游**：选定省份，自动给出省内精华城市串联方案。
- **行程风格**：特种兵 / 休闲 / 平衡，影响每日景点密度。
- **旅行模式**：亲子 / 情侣 / 独行 / 老人，调整景点类型与节奏。
- **往返大交通核算**：去程 / 返程交通一并计入总预算与时间表。
- **多方案对比**：同条件下可生成多套方案横向比较。

## 二、行程呈现（「行程」页）
- **逐日时间线**：每天「几点到几点」干什么，行程项居中、可点击展开详情。
- **攻略自评分**：离线计算 0–100 分 + 等级（优秀 / 良好 / 尚可 / 待优化）+ 三维度（紧凑度 / 覆盖度 / 节奏均衡）+ 改进建议。
- **动线优化**：同一天多景点按地理就近「最近邻贪心」重排，少走回头路，地图当天连线更连贯。
- **一键导航**：直接拉起地图 App 导航到指定景点。
- **拖拽调序**：行程内景点可手动拖动改变顺序。
- **保存到我的攻略 + 多行程管理**：本地存档最多 10 份，同签名自动覆盖，可浏览 / 恢复 / 删除。
- **预算进度条**：花费 vs 预算可视化。
- **旅行足迹 / 成就**：景点打卡、城市点亮、成就徽章。

## 三、地图导引（map 页）
- **pin 与攻略一一对应**：地图编号标点即攻略内景点，不会错位。
- **当天路线连线**：按重排顺序把当天景点连成线，动线清晰。
- **多图层**：景点 / 美食 / 住宿 可叠加切换。
- **导航兜底**：坐标缺失时回退城市锚点，避免死链。

## 四、美食（food 页）
- **真实坐标店铺**：覆盖 404 城 / 6904 家，带经纬度可直接导航。
- **富信息（20 城 263 家）**：菜单、口碑（rep）、点评笔记。
- **美食动线**：早市 → 老店 → 宵夜 三站吃法建议。
- **按菜名 / 标签搜店**：菜名直接定位对应店铺。

## 五、酒店
- **多片区住宿区域**：约 60 个热门城各 3–4 个片区，含参考价区间（如「参考¥300-500/晚」）。
- **13 个门户比价**：去哪儿 / 艺龙 / 途家 / Airbnb / 小红书 / 抖音 / 高德等，仅复制搜索词比价，**不内嵌交易页**（合规红线）。
- **酒店地图图层**：片区在地图上标出。

## 六、记账（ledger 页）
- **分类记账**：吃 / 住 / 行 / 门票 / 购物 分大类。
- **多人 AA 分账**：记录付款人，自动计算谁该给谁多少。
- **当日 vs 总预算**：实时对比，超支预警。
- **导出 CSV**：一键导出对账。
- **速记**：名称 + 金额快速记一笔。

## 七、行前准备（prep 页）
- **票务勾选清单** + **行李清单**。
- **预约横幅 / 预约时间表**：把「该提前几天约」的景点按提前量排序。
- **行前三件事**：预约 / 闭馆 / 早起提醒自动聚合。

## 八、天气（`utils/weather.js`）
- **和风 7 天预报**，按行程各城市分别拉取。
- 含体感、湿度、UV、日出日落。
- **盘上缓存 30 分钟** + **雨雪备选**：下雨自动推荐室内 / 半室内景点。

## 九、旅途应急（help 页）
- **应急分诊**：输入症状 → 给出处理建议与优先级。
- **具名真实医院**：156 家 / 125 城（全部真实，无模板编造）。
- **地图搜附近**：其余 326 城降级为「在地图中搜附近医院」，不列虚假机构名。

## 十、个性推荐与旅行画像
- **旅行画像测试题**：答题生成旅行偏好画像并存储。
- **跨会话偏好学习**：记录上次城市 / 天数 / 节奏 / 预算 / 偏好，下次自动回填（深链已指定的项不覆盖）。
- **个性化推荐引擎**：结合本机真实数据给出「为什么推荐这城」的理由；1.19.201 新增全年时令稳定性护栏。

## 十一、AI 与深度内容
- **AI 旅行伴侣（assistant）**：基于本地知识库的问答，不依赖外网。
- **深度内容（subai 分包）**：Top 城深度玩法，激励视频解锁（合规广告位）。

## 十二、工具集（toolkit 页，30 个工具）
- **行程体检**：行程速览 / 密度排行 / 摄影时刻 / 行前三件事 / 预约时间表 / 风险提示卡
- **文案与分享**：行程总述 / 一句话发圈 / 朋友圈长文案 / 逐日看点
- **城市·灵感**：去这里的理由 / 城市彩蛋 / 美食动线 / 住哪儿好 / 怎么去怎么走
- **出发前·实用**：出发倒计时 / 花钱速度 / 穿衣建议 / 常备药 / 高反风险 / 防骗提醒 / 新手易错
- **当地·百科**：最佳月份 / 辣度地图 / 必吃 TOP3 / 美食街区 / 伴手礼 / 当地禁忌
- **行程中·备选**：当天最值 / 夜间去处 / 雨天备选 / 错峰建议 / 周边城市

## 十三、数据与离线底座
- **离线知识库·大数据（`utils/corpus.js`）**：聚合 751 城 / 24358 点坐标 / 26357 条体验的真实体量。
- **本机数据洞察（`utils/insights.js`）**：基于本机设备的统计。
- **坐标防幻觉 + 完整性自检**：优先真实坐标；加载期 / 打包期双重越界门禁（>300km 且跨省 或 >1200km 直接拦截）。

## 十四、体验与系统
- **双主题**（浅 / 深）+ **字号无障碍**（跟随系统字号 + 三档手动）。
- **使用指南**（18 条，首次自动展开）。
- **合规与密钥**：运行时填入本人申请的第三方 Key（和风 / 高德）即时生效，无需改代码重发版。
- **分享深链复现**：带参数分享，对方打开自动生成同款行程（确定性输出）。
- **空态插画 + 悬浮动效**：各页空状态统一玻璃卡片风格。

## 附：技术栈速览
- **运行时代码**：原生微信小程序 —— JavaScript（逻辑）+ WXML（结构）+ WXSS（样式）+ JSON（配置）。
- **数据与构建工具链**：Node.js（ESM，如 `pack-data.mjs` / `build-min.mjs` / `allcheck.sh` 调用的单测；压缩用 `pako`，分包懒加载用 `require.async`）。
- **图标真源**：Python 3（`_gen-tab-icons.py`，Pillow 5× 超采样渲染 Tab 图标）。
- **上传 / 回归脚本**：Shell（Bash，`upload.sh` / `allcheck.sh`）。
- **数据载体**：JS 对象字面量 → deflate 压缩为 `subdata/data/data-packed.js`（约 1828KB）随分包异步加载。
- **合规要点**：个人主体无微信认证，故数据全部静态随包离线、不内嵌 web-view / 交易页；第三方 Key 运行时覆盖。
