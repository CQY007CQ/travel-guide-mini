## 一、开场（疑问式引入）【轻松、像聊天、环视观众】

先问大家几个"扎心"的小问题啊——

出门玩，尤其是几个人一块儿的时候：

- 是不是**一笔一笔的账记到头大**？今天谁垫了饭钱、明天谁买了门票，到最后一天还得坐下来一笔笔算、算谁该给谁多少，特别烦？
- 去之前在网上搜攻略，一堆"人上人"的分享刷出来，**真假难辨**；可真到了地方，你还是不知道**周几该去哪个景点、这俩景点离多远**——结果每天都在城里来回奔波，光路上就耗掉大半天；
- 更坑的是，**根本不知道景点要不要预约、几点关门**，兴冲冲跑过去，人家闭馆或者要提前三天抢票，精彩的内容全错过了；
- 还有，对景点本身其实**了解得很浅**——光知道"是个有名的地方"，它到底有啥、怎么玩才不白来，心里完全没底；
- **出门怕抓瞎**：突然下雨去哪、身体不舒服附近有没有靠谱医院、穿什么衣服——这些小事，真到了外地全得现想。

这些是不是都特别真实、特别烦？我们当时就是被这些小事反复折磨，才想做点东西。

## 二、引出产品【自然转折】

所以我们做了这款微信小程序——「旅行攻略生成器」。

它最大的好处，就是**不用专门下个几十兆的 App**。以微信为载体，搜一搜、扫个码就能开，随用随走，特别轻。

一句话定位：**你告诉我去哪、玩几天、什么节奏，它十几秒就给你排出一份能直接照着走的旅行攻略**——吃什么、住哪片、每天几点去哪、怎么走最顺，全都安排好。

那它怎么解决刚才那些麻烦？我挑几个最"痛"的，对应着说——

## 三、痛点 → 核心功能（重点，慢讲，每个点完可现场演示）

**① 多人记账太乱 → 它内置了"旅行记账"**
几个人出行，不用最后抱头痛算。账本里支持**分类记账**（吃、住、行、门票、购物分得清清楚楚）、**多人 AA 分账**，还能看**当日花了多少 vs 总预算**，最后**一键导出 CSV**，谁欠谁一目了然。再也不用旅程结束坐那对账到半夜。

**② 信息真假难辨、人上人攻略不靠谱 → 它用的是自己整理的离线真实数据库**
我们没有去抓营销号，而是内置了覆盖**全国 751 座城市、2.6 万多个真实景点体验**的数据，美食、酒店都带真实坐标和评价。行程生成后它还会自己**打一个"攻略评分"**，告诉你哪天太赶、哪里能优化——比刷网红攻略靠谱得多。

**③ 不知道景点离多远、天天奔波 → 它做了"动线优化"**
同一天里的景点，它会按地理位置**就近串起来**，地图上的点跟攻略一一对应、当天还画线连起来，**少走回头路**，不会出现在地图上画大叉、跨城来回跑的情况。

**④ 不知道要不要预约、几点关门 → 它把"预约提示 + 开放时间"内置进去了**
生成行程的时候，需要预约的、临近闭馆的，它都会**提前标红提醒**帮你避开"白跑一趟"；同时给出**逐日时间线**（每天"几点到几点"干什么），点开每项还能看详情。

**⑤ 对景点了解太浅、出门怕抓瞎 → 它每个景点都内置了详细介绍 + 应急兜底**
不用退出微信去百度现查。每个景点有什么看点、怎么玩，小程序里**离线就能看**——既快，也不依赖外网，更合规。
- **天气**：拉和风 7 天预报，连体感、湿度、紫外线、日出日落都有；下雨了自动给你**推室内备选**。
- **应急**：真不舒服，输入症状给**分诊建议**；附近医院只列**真实具名**的那 156 家，绝不编造机构名。

**⑥ 越用越懂你【指向画像 / AI】**
它不是冷冰冰的模板。你答几道**旅行画像**题，它就记住你的偏好；下次打开**自动回填**上次的城市、节奏、预算。**AI 旅行伴侣**还能基于本地知识库随时问答，不依赖外网。

**⑦ 30 个随身小工具【指向工具集】**
除了攻略本身，还塞了一个**工具箱**：行程体检、发圈文案、穿衣建议、常备药、防骗提醒、当地禁忌、最佳月份……**30 个**围绕出行的实用工具，随时查。

**⑧ 底气来自数据（可略，或配合大屏）**
所有这些推荐，不是拍脑袋。底座是**覆盖 751 城、2.4 万多真实坐标点、2.6 万多条体验**的离线数据库，而且我们对坐标有**双重防错门禁**，绝不让一个景点标到千里之外。

> 技术合规亮点（评审时补充，30 秒）：它是**原生微信小程序**，数据**全部静态随包、离线可用**，不依赖服务器；第三方天气 / 地图 Key 走**运行时合规覆盖**，不用改代码重发版；个人主体下严格遵守"不内嵌网页、不内嵌交易"的合规红线。

## 附录 A · 现场演示点击顺序（给自己看的提词）

只讲"产品完成度"，按这个顺序点最稳：

1. **打开方式**：微信搜 / 扫码 → 强调"无需下载 App、轻量"。
2. **生成行程**：首页 城市 + 天数 + 节奏（轻松 / 标准 / 紧凑）→ 逐日攻略；可叠加 预算档 / 人数 / 旅行模式 / 多站串联 / 全省精华游。
3. **行程评分 + 动线 / 地图**：评分卡（0–100 分） + 地图 pin 与攻略一一对应、当天连线（对应痛点③④）。
4. **预约 / 开放时间**：景点卡片上的"需预约 / 开放时间"标红（对应痛点④）。
5. **美食 / 酒店**：真实坐标 + 菜单口碑 + 参考价区间 + 多平台比价（不内嵌交易）。
6. **记账（重点）**：分类 + 多人 AA + 当日 / 总计对比 + 导出 CSV（对应痛点①）。
7. **天气 / 应急**：雨雪备选 + 真实具名医院（对应痛点⑤）。
8. **景点详情 / AI 伴侣**：离线详情，强调"不用跳出微信去百度，自己的数据就够"（对应痛点⑤）。
9. **工具集 / 画像**：可酌情展示 30 个工具与旅行画像自动回填。

> 加分项：把**记账**和**预约 / 开放时间**作为两个新亮点重点演示，最出彩也最容易拿"完成度"的分。讲"详情"时顺口提一句"不用跳出微信去百度，我们自己的数据就够"，既真实又显专业。
