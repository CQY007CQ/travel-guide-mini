# 文档中心（docs/）

本目录集中存放项目的**非运行时文档**，均不参与微信小程序的编译与打包。

项目根目录原本散落约 35 个 `.md` / `.html`（版本变更、审核描述、技术方案、架构、优化清单等），于 2026-10-19 按性质分层归集到此处，让根目录只保留运行与入口文件（`README.md`、`allcheck.sh`、`app.*`、`project.config.json`、`sitemap.json`）。

## 目录结构

- **`changelog/`** —— 版本演进记录。每个版本的变更清单、审核描述、隐患排查、路线图。
  - 示例：`v1.19.82-审核描述.md`、`v1.15-变更清单.md`、`v1.14-路线图.md`、`v1.10.1-隐患排查与修复报告.md`
- **`design/`** —— 架构、技术方案与体验设计。
  - `ARCHITECTURE.md`：项目架构总览
- **`assessment/`** —— 考核 / 评审用材料。
  - `功能清单.md`：功能字典（按模块梳理已实现功能，文末单列「考后规划中」）。
  - `演示讲稿.md`：演示讲稿（「疑问式开场」与「边看边讲」双版本合一，含演示点击顺序与未来规划附录）。
  - `B2-包体安全线核查报告.md`：分包体积 2MB 红线核查
  - `真实体验10项改进-v1.19.9.md`：真实体验复盘
  - `100项优化清单.md` / `300项优化清单.md` / `500项优化清单.md`：优化 backlog（由 `tools/_gen-300.mjs` / `tools/_gen-500.mjs` 生成，脚本内的输出路径已固定指向本目录）
  - `v1.20-*.md`：后续版本技术方案（云后端与 AI 行程、高德合规加固、外借 KEY 事故处置与沟通、旅行排行榜、deep 扩容候选等）
- **`朋友圈分享卡.html`** —— 分享卡片素材 / 模板。

## 约定

- 项目根 `README.md` 是工程入口说明，本目录是其配套的文档归档。
- 这些文档**不会被微信开发者工具编译进小程序包**，仅作为研发资料与历史追溯。
- 优化清单由生成脚本产出，输出路径已对齐到 `docs/design/`，重跑脚本无需手动搬运。
