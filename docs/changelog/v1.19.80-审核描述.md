## 本次更新

1. **同名「X市」↔「X」归并（数据可用性修复）**
   库里同时存在「安康」(有数据) 与「安康市」(零景点) 这类重名条目，用户选/搜「安康市」会生成空白行程。新增 `canonCityName` 把名称收敛到「带数据的那个」变体（优先原样 → 剥「市」 → 补「市」），在名称解析总闸 `findCity` 落地。
   - 实测 **291 个**零景点「X市」城市因此归并到已有数据的「X」，可用城市从 **423 → 714（+69%）**，无需新增任何地理编码。
   - 剩余 37 个真正零景点城市为自治州/地区/盟（如「阿坝藏族羌族自治州」），由 planner 的省级地标兜底生成，不崩溃。

2. **选择列表去重（`citiesOf`）**
   省份城市选择器不再展示会生成空白的零景点「X市」，只保留带数据的 canonical 名，避免用户选到死城。

3. **防御性名称归一**
   `foodSpotsFor` / `spotTagOf` / `nearbyCityOf` 等按城市名取数的入口统一走 `canonCityName`，兼容历史已保存行程里残留的「X市」写法（如旧行程 `cityName` 为「安康市」也能正确取美食/标签/坐标）。
