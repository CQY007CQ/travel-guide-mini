# v1.19.77 审核描述

**版本号**：1.19.77
**类型**：体验优化（纯前端，无新增权限、无新增数据采集、无后端依赖）

## 本次更新

1. **热门路线一键套用**
   出发页新增「热门路线」横向卡片（西安 4 天 / 成都 4 天 / 重庆 3 天 / 北京 5 天 / 杭州 3 天 / 厦门 3 天 / 大理 4 天 / 桂林 4 天 / 青岛 3 天 / 敦煌 3 天）。
   点击即自动填好目的地与天数，省掉「选省 → 搜城市 → 调天数」三步。天数会按该城市真实可玩量自动收敛，不会出现排不满的空天。

2. **行程内景点可拖动排序**
   每日行程每条右侧新增六点手柄，按住上下拖动即可调整当天游览顺序，松手生效。
   - 时段（上午 / 下午 / 晚上）跟随「坑位」而不是景点，调换后行程行文自动归一，不会出现病句；
   - 「抵达 / 返程」等框架行不可拖动；
   - 原「↑ 上移 / ↓ 下移」按钮保留，作为兜底操作。
   - 手柄只挂在按钮本身，不影响页面正常上下滚动。

3. **视觉微动效**
   - 每日行程卡首次进入时错落渐入，编辑 / 打卡后的重渲染不再重放，避免整页闪动；
   - 顶部天数导航 chip、工具按钮、详情操作按钮增加按压回弹反馈；
   - 时间线展开详情的过渡更柔和；
   - 已适配系统「减少动画」偏好，开启后全部动效自动关闭。

4. **分享长图与深链（v1.19.76 延续）**
   行程页可生成分享长图并转发 / 存相册；分享出去的链接带城市与天数参数，对方点开直达已填好的出发页。

## 不涉及

- 不收集任何用户隐私信息，不获取位置、通讯录、相册写入以外的权限；
- 无用户生成内容（UGC）发布与传播功能；
- 不涉及网络预约车、外卖、医疗、金融、新闻等需前置许可的类目；
- 无支付、无交易、无第三方跳转带货。
