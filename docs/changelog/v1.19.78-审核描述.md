# v1.19.78 审核描述

**版本号**：1.19.78
**类型**：内容增强 + 体验增强（纯前端，无新增权限、无新增数据采集、无强制后端依赖）

## 本次更新

1. **「深玩」分包（subai，新增独立分包，零挤占数据红线）**
   离线打包 10 城人工整理的深度玩法（北京 / 上海 / 西安 / 成都 / 重庆 / 杭州 / 南京 / 广州 / 厦门 / 青岛），每城含 4 个板块：本地人的节奏、避坑清单、取景机位、顺手加一日。内容为人工整理离线文本，**非实时 AI 生成**，不适用《生成合成内容标识办法》的 AI 标识要求。

2. **激励视频解锁深玩（增强项，零阻塞）**
   当前行程所在城市免费看；切换其他城市需看激励视频解锁。设计 fail-open：未配置广告位 / 广告故障 / 加载失败时自动全解锁，绝不阻断主流程；半程退出视频不给奖励。默认 `ENABLED=false`、`AD_UNIT_ID=""`，即全免费。

3. **出发提醒（日历兜底 + 可选订阅）**
   行程页新增「出发提醒」入口。无服务端时默认走系统日历（`wx.addPhoneCalendar`）——个人主体唯一真能响铃的本地通道；配置订阅模板 ID 后可切云端订阅消息。全部 try 包死，任意通道不可用均自动降级。

4. **网页版 PWA 化**
   单文件网页版注入 `manifest.webmanifest` + Service Worker（stale-while-revalidate），离线可开；含 192/512 图标与 apple-touch-icon。改动不进小程序包体（在 `outputs/` 目录，已加入上传忽略列表）。

5. **包体红线核算修正**
   allcheck「主包体积预警」原实现把全项目（含 1.7MB 数据分包）累加成一个数去比对 2MB，必然误报。改为按微信「每包独立 2MB 压缩后红线」逐包核算（`tools/check-pkgsize.mjs`），与项目既有的分包架构一致。

## 不涉及

- 不收集任何用户隐私信息，不获取位置、通讯录、相册写入以外的权限；
- 无用户生成内容（UGC）发布与传播功能；
- 不涉及网络预约车、外卖、医疗、金融、新闻等需前置许可的类目；
- 无支付、无交易、无第三方跳转带货；
- 无实时生成式 AI 对话（个人主体无法上线「深度合成 - AI 问答」类目）；深玩内容为预生成离线文本。
