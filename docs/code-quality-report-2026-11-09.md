## 4. 本轮修复（真 bug）

1. **省游候选池「填充词景点」导致空天**（由 #491 模糊测试发现）
   - 现象： `buildProvincePlanDays` 候选池原样收录含填充词的具体名店（庙街夜市 / 士林夜市 / 古运河夜游），被单独排成一天后按 `isFrameName` 口径判为空天。
   - 影响：香港 7 天 leisure D4、台湾 3 天 leisure D2、江苏 10 天 leisure D8 等。
   - 修复：候选池排除 `_isFillerSpotName` 命中项（填充词表与 `isFrameName` 一致；planner 不 require travel 以免循环依赖）。
   - 验证：全 34 省 × 6 天数 × 3 节奏 **612 项，leisure 空天 11 → 0**。

2. **模糊测试 harness 自身缺陷**（非产品 bug，如实记录）
   - 现象：按 `cityDayCap(city,"balance")` 截断天数却按随机节奏构建（`speed` cap 系统性低于 `balance`，如漠河 9 vs 14）→ 超发造出 45 个假空天。
   - 修复：按**实际节奏**取 cap；limited 城空天属预期不计（与 `_scan-sparse` 口径一致）；补回三沙经纬度特例。
   - 结果：fuzz 340 次构建 **0 异常 / 0 NaN / 0 坐标越界 / 0 空天**。

3. **发布代码洁净度**：移除 `web/app.js` 调试 `console.log` 与无用变量 `t0`；**新增永久门禁**（见下）。
